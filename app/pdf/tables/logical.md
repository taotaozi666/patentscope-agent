# 逻辑表组装与检索关联（第 6 项）

入口为 `assembly.assemble_tables()`，在逐页解析、章节识别和专利抽取后执行。解析器 native-v14、组装 logical-tables-v1、语义对象 v6、切片 v10、质量规则 v5。

## 表头与数据行

优先采用后端声明的表头行。原生后端没有语义表头时，使用“前部非数值区域 → 数值数据行”的有限启发式；带 Sample/Metric/实施例等明确首列名并紧接数值行时，可识别含年份的首行表头。推断方式写入 `TableFragment.header_method`，不冒充后端结果。

按列及合并跨度，沿表头层级生成单元格 ID 路径。例如 Properties → Strength MPa；数据格同时引用左侧连续文字标识列，合并行标识引用真实锚点。已识别单位的表头格写入 `unit_cell_ids`，不把单位写入数值原文。

缺乏数值过渡的纯文字表、以数值开头且没有明确表头证据的表，保持未知表头。所有行按数据保留，质量报告提示复核。`LogicalTable.structure_status` 保持 partial，表达这些关联尚需业务核验；几何完整不等于语义准确。

## 跨页续接

自动合并必须满足：相邻页、列数相同、完整表头路径文字一致（包含原单位文字）、章节相同、表格左右边界接近，且不存在表号或显式单位冲突。再满足以下任一条件：

- 表号相同，续页标题明确出现 continued/续。
- 前片段在页尾，后片段在页首，后片段没有新表号。

仅同名或表头相同但缺少续接证据时，保存相互的 `continuation_candidate_ids`，维持独立并提示复核。不同表号、单位、章节、非相邻页及明显边界不一致均阻止续接。结果理由写入 `continuation_decision`。

重复表头从逻辑数据行中排除，但其单元格 ID 仍保存在 `repeated_header_cell_ids`；各页数值仍引用本页的表头与来源。当前不自动续接缺少表头的后页，不修复被分页切断的半行，也不进行列重排或单位换算。

## 标题、单位与脚注

短的邻近标题、单位声明和注释按水平重叠、距离及最近表格归属绑定；标题取上方，注释取下方。同页多个表格避免共用一个邻近说明。保存原文和独立 SourceSpan，不写进数据单元格。单位声明作用于逻辑表；目前不解析脚注符号指向某个数值的细粒度关系。

## 检索与兼容

一个逻辑表生成一个语义父对象，保留全部页内片段来源。切片按数据行预算拆分，携带完整表头区域；超宽行按单元格拆分。合并格值不会复制到覆盖位置，相关行标识通过上下文引用传递。

片段新增 `table_cell_relations`（JSON：行表头、列表头、单位格及支持原文/坐标）、`table_fragment_ids` 和 `table_header_status`。关联上下文有长度上限；结构元数据保留完整引用。原始数值仍在 page_content，字符映射回到原单元格。历史数据没有逻辑表时继续使用原来的表格对象路径。

第 7 项进一步升级为语义对象 v7、切片 v11，支持宽表列组及检索后同版本原始证据补齐，见 [retrieval.md](retrieval.md)。

质量检查报告未知表头和待确认续接，失效的行列/单位单元格引用会阻止入库。保存新增字段时仍使用 schema v1 的可选默认值，旧文件可恢复；恢复不会替旧资产重新推断语义。

## 验证边界

`tests/test_logical_tables.py` 验证固定独立标注、多级表头、合并行标识、双页来源、重复表头、明确续表、真实页尾/页首续表、同名候选、表号/单位/章节/位置冲突、未知首行与零值保留、持久化及错误引用。

合成回归报告新增 header_association 与 logical_table_grouping。单位规范化与脚注语义仍未作为完整验收，target_complete 保持 false。扫描表的真实效果取决于 OCR 和表格模型；不能用原生结构测试推断扫描识别准确率。
