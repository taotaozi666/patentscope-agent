# 表格质量检查与复核（第 8 项）

规则版本 pdf-quality-v6，切片版本 semantic-chunks-v12。原生解析器仍为 native-v14，语义父对象 v7。处理指纹包含质量规则版本；历史资产不会因代码升级自动重新解析或重建向量。

## 自动检查与使用状态

表格检查在原有正文、OCR 和来源检查之外执行：

| 情况 | 自动处理 |
| --- | --- |
| 跨度越界、确认跨度重叠、完整网格出现空洞、占位锚点错误 | blocked |
| 单元格标识/表头/单位引用错误，表头引用与行列不符 | blocked |
| 来源越页、超出表格、值或字符区间与原格不一致、切片所属逻辑表错误 | blocked |
| 逻辑片段缺失/共用、表头路径不一致、数据行错位、错误续接或重复表头引用丢失 | blocked |
| 表号、表头单位、章节、页序等续表条件冲突 | blocked |
| 未知跨度/表头/内容、缺少来源、未完整验证结构或后端回退 | review |
| OCR、模型或未知文字通道的表格识别结果，尚无准确率验收 | review |
| 漏索引、重复索引数据字符、OCR 冲突、候选续接 | review |

空白格与字符串零保持区分。未知跨度不会冒充跨度 1；因未知跨度造成的覆盖不确定性进入复核，不当作确认重叠。超过 100000 个位置的网格不展开全量覆盖检查，标记复核。

报告新增 tables：每张逻辑表（历史数据可为页内表）的片段、单元格、页码、问题编号及使用状态。blocked 为禁止数值问答；reference_only 为仅供原文参考、数值需复核；traceable 为规则通过、可追溯原文。traceable 不表示 OCR 或语义准确率通过人工验收。

问题同时保存 table_id、cell_ids、source_spans，点击问题可以定位具体来源。新增字段具有默认值，旧报告继续可读；旧报告没有表格级结论时提示更新检查，不推定为通过。

## 复核页面

“解析检查”页增加逻辑表选择、物理片段选择、结构网格和单元格定位。网格展示合并锚点/占位、空白和未知状态，不填造数据值。超过 200 行或 40 列的结构预览明确标注截取范围。

选择值格后，展示其行标识、列表头、单位原文及物理页码。原 PDF 的内存副本上绘制红色值格、蓝色行标识、绿色列表头和紫色单位；切换续页会使用对应物理页。缺失/无效坐标不绘框，不修改原始 PDF。OCR 冲突的备选结果及续表判定详情可直接复核。

人工范围增加 table:ID 与 cell:TABLE_ID:CELL_ID，均校验是否属于当前报告。人工结论与自动规则分开保存，标记“通过”不会抹除规则问题或解除结构阻断；标记“有问题”会使后续检索降为仅供原文参考。表格结构与来源也包含在检查报告导出的 JSON 中。

## 检索使用门槛

补证据时读取包含该 pdf_chunk_id 的检查报告，并核对规则版本。不会借用另一套切片预算或旧切片版本的报告。没有当前表格报告时按仅供原文参考处理。

已阻断文档/表格的原始命中仍可在来源中查看，但 answer() 不把这些表格的数值或支持原文发给回答模型。即使父对象损坏导致补证失败，已经确认的阻断状态也会保留。其他不完整证据带明确提示，不能作为已核实的精确结论。

历史自动检查只选择最后保存的切片配置，配置包括大小、目标预算、上下文模式/模型、切片器版本及解析器版本，避免混入历史重复切片。旧 v11 切片需重新导入后采用 v12；更新检查本身只重跑规则，不重新切片或解析。

## 验证与剩余边界

核心回归包括故意制造的覆盖冲突、网格空洞、错页/错值/错误表头、错误续表、漏索引和失效证据；UI 测试验证网格选择、续页高亮、单元格复核保存及原有来源展示。原生回归脚本的 report.json 现在同时包含 quality_report。

8 项队列的代码接入已完成。完整 Docling 推理、真实 OCR、人工标注的真实混合专利样本、单位规范化及细粒度脚注语义仍没有完成验收，不能据合成测试宣称复杂表格精确数值问答已全面可用。
